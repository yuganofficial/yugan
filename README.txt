YUGAN Affiliate Website — Version 2

Included:
- index.html — responsive multi-category storefront
- privacy.html — starter privacy page
- disclaimer.html — affiliate disclosure starter page

Affiliate platforms supported in the product data:
- Amazon
- Flipkart
- Meesho

Before launch:
1. Open index.html in a code editor.
2. Find `const products = [` in the script near the bottom.
3. For each product, add the approved affiliate URLs in amazonUrl, flipkartUrl and meeshoUrl.
4. Add a permitted product image URL in imageUrl and update price/name/description.
5. Empty store URLs intentionally show as disabled labels; no fake shopping links are created.
6. Test the site on mobile and desktop.

Important:
- The products are sample placeholders, not verified listings.
- This package does not create affiliate accounts or generate tracking links.
- Use only affiliate links issued to your account and images permitted by the retailer/program.
- The website is static and can be hosted free on GitHub Pages or Netlify. It has no admin login/database.

Free deployment:
GitHub Pages: create a repository, upload the three HTML files, then enable Pages in repository Settings.
Netlify: use manual deploy and upload the folder.
